**1. Upgrade `internal/httpx/middleware_maintenance.go` (OPS-05):**

Replace the pass-through stub with functional middleware that reads from settings table. The middleware needs a `*metadata.SettingsRepo` parameter. Update the signature:

```go
func MaintenanceMode(settings *metadata.SettingsRepo) func(next http.Handler) http.Handler
```

Logic:
- GET, HEAD, OPTIONS always pass through (reads allowed per OPS-05)
- For other methods, read `settings.Get(ctx, "maintenance_mode")`
- If value == "true", return 503 with `{"error":"maintenance","detail":"Write operations disabled during maintenance"}` and `Retry-After: 300` header
- Otherwise pass through
- If settings is nil (test mode), pass through (backward compat)

Update `internal/httpx/router.go` to pass settings to MaintenanceMode. This requires adding `Settings *metadata.SettingsRepo` to `httpx.Deps`. Adjust the `New(d Deps)` call to pass `d.Settings` to `MaintenanceMode(d.Settings)`.

Update all callers of `httpx.New()` in `internal/app/` and test files.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> admin endpoints | Super-admin-only actions; auth gate is critical |
| client -> Trivy DB upload | Untrusted tarball extracted to filesystem |
| client -> audit filters | User-supplied query params into SQL WHERE |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | admin_trivy.go upload | mitigate | Validate tarball is tar.gz; extract to temp dir under DataRoot/tmp/ only; atomic rename; no path traversal (strip leading / from tar entries; reject entries with ..) |
| T-05-03-02 | Elevation | admin endpoints | mitigate | Every admin endpoint gated by RequireCan with super-admin action |
| T-05-03-03 | Tampering | admin_audit.go filters | mitigate | All filter values passed as parameterized ? to SQL; never string-concat |
| T-05-03-04 | Denial of Service | maintenance toggle | mitigate | Toggle requires super-admin; middleware short-circuits with 503 (no DB query per request during heavy load -- cache setting with short TTL or accept the single SELECT) |
| T-05-03-05 | Info Disclosure | TLS history | mitigate | TLS history endpoint gated by super-admin; only returns metadata (subject, expiry), not private keys |
</threat_model>
