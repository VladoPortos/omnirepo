**1. `internal/httpx/spa.go` (UI-02):**

```go
package httpx

import (
    "io/fs"
    "net/http"
    "strings"
)

func SPAHandler(distFS fs.FS) http.HandlerFunc {
    sub, err := fs.Sub(distFS, "dist")
    if err != nil {
        panic("spa: " + err.Error())
    }
    fileServer := http.FileServer(http.FS(sub))

    return func(w http.ResponseWriter, r *http.Request) {
        path := strings.TrimPrefix(r.URL.Path, "/")
        if path == "" {
            path = "index.html"
        }
        // Try serving the exact file
        if _, err := fs.Stat(sub, path); err == nil {
            fileServer.ServeHTTP(w, r)
            return
        }
        // SPA fallback: serve index.html for client-side routing
        r.URL.Path = "/"
        fileServer.ServeHTTP(w, r)
    }
}
```

This handler is mounted LAST on the router as the NotFound handler, after all API/protocol mounts (pitfall P2 from RESEARCH.md).

**2. `internal/httpx/devproxy.go` (UI-03, D-33):**

```go
package httpx

import (
    "net/http"
    "net/http/httputil"
    "net/url"
    "os"
)

func DevProxy() http.Handler {
    target, _ := url.Parse("http://localhost:5173")
    return httputil.NewSingleHostReverseProxy(target)
}

func IsDevMode() bool {
    return os.Getenv("OMNIREPO_DEV") == "1"
}
```

When OMNIREPO_DEV=1, the router uses DevProxy() as the NotFound handler instead of SPAHandler.

**4. `internal/api/git_browse.go` (D-11, D-32):**

Mount: `func (d Deps) mountGitBrowse(r chi.Router)`

Endpoints use go-git v6 to walk the repository. The Git repos live at `d.DataRoot/repos/<project>/git/<repo>.git/`.

- `GET /api/v1/projects/{name}/repos/git/{repo}/refs` — list branches and tags from git_refs table
- `GET /api/v1/projects/{name}/repos/git/{repo}/tree/{ref}/{path...}` — list directory entries at path in ref. Use go-git to open the bare repo, resolve ref to commit, walk tree. Return: `[{name, type: "file"|"dir", size, last_commit_msg}]`
- `GET /api/v1/projects/{name}/repos/git/{repo}/blob/{ref}/{path...}` — return file content at path. Include content as string (for text) or base64 (for binary). Detect text/binary by checking for null bytes in first 8KB.
- `GET /api/v1/projects/{name}/repos/git/{repo}/commits/{ref}?limit=&cursor=` — paginated commit log for ref. Return: `[{sha, author, email, date, message}]`
- `GET /api/v1/projects/{name}/repos/git/{repo}/commit/{sha}` — single commit detail + diff (list of changed files with added/removed line counts and patch text)
- `GET /api/v1/projects/{name}/repos/git/{repo}/blame/{ref}/{path...}` — per-line blame for file
- `GET /api/v1/projects/{name}/repos/git/{repo}/compare/{base}...{head}` — diff between two refs

Auth: project membership check. Use go-git's in-memory plumbing (not subprocesses).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> search query | User-supplied text into FTS5 MATCH |
| client -> git path params | User-supplied ref/path into go-git tree walking |
| client -> SPA handler | Any path served as index.html if not matched |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | git_browse.go path traversal | mitigate | Validate ref exists via go-git resolve; path is within the tree (go-git tree entry lookup rejects ../ naturally); never construct filesystem paths from user input |
| T-05-04-02 | Denial of Service | git_browse.go blame on huge file | mitigate | Limit blob response to 5 MB; limit blame to files under 1 MB; return 413 for oversized |
| T-05-04-03 | Info Disclosure | SPA fallback serving internal files | mitigate | SPAHandler only serves from embedded dist/ FS (go:embed); cannot access filesystem outside embedded assets |
| T-05-04-04 | Spoofing | open redirect via SPA | mitigate | SPA routing is client-side; server always returns index.html for unknown paths; no server-side redirects |
</threat_model>
