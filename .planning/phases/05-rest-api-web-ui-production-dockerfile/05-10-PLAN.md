**2. `web/src/pages/ProfilePage.tsx` (D-26):**

Sections:

**Personal Information:**
- Avatar preview (dicebear from seed, with "Regenerate" button that randomizes seed)
- Edit Email (Input)
- Edit Avatar Seed (hidden, auto-updated on regenerate)
- "Save Changes" button (PATCH /api/v1/me)

**Change Password:**
- Current Password, New Password, Confirm New Password fields
- "Update Password" CTA
- Validation: passwords match, min length
- Uses changePassword mutation from useAuth

**API Keys (D-26):**
- Table: Name, Key Prefix (monospace), Created, Last Used
- "Create API Key" button opens Dialog:
  - Name field
  - On submit: POST /api/v1/me/api-keys
  - Dialog transitions to OneTimeReveal: "Your API Key" heading, warning "This key will not be shown again. Copy it now.", Copy button
- "Revoke" button per key: confirmation dialog "Revoke API Key: This key will stop working immediately. Continue?"

**S3 Access Keys (D-26):**
- Table per project: Access Key ID, Label, Created
- "Create S3 Key" button opens Dialog:
  - Project selector (dropdown of user's projects), Label field
  - On submit: POST /api/v1/me/s3-keys
  - Dialog transitions to OneTimeReveal: "Your S3 Secret" heading, warning "This secret will not be shown again. Copy it now."
- "Revoke" button per key

**My Projects:**
- Read-only list of project memberships with links to project detail

**Delete Account:**
- "Delete Account" button (destructive) at bottom
- Confirmation: "Delete Account: This will permanently remove your account and all personal API keys. You will be logged out immediately. Type your login to confirm."
- Typed confirmation required
