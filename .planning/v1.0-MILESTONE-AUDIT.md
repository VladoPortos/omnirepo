## Tech debt carried into v1.1

Three items, none of which are v1.0 blockers (documented in
`NEXT-SESSION-ISSUES.md` at repo root):

1. **Docker shared-blob storage overestimate.** `repoSizeExpr` fully
   charges each blob to every referencing repo (N× overcount for shared
   blobs). Intentional for operator mental model; revisit when
   billing/quota work starts.
2. **DEB `resolveDebPoolPath` exotic layouts.** Assumes standard Debian
   pool layout `pool/<component>/<lp>/<pkg>/<filename>`; repos with
   non-letter sharding or custom components will 404. Handler is
   defensive (mis-resolution → 404, not corruption).
3. **Codex rescue pass across 2026-04-17 shipping.** `s3_buckets.go`,
   walkthrough harness, dashboard extensions, S3BucketPage rewrite,
   `admin_gc.go` status handler — all shipped without a Codex rescue
   review because the prior Codex run hung ~1 h. Worth one time-boxed
   pass early in v1.1.
