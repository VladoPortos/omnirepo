# scripts/typography-allowlist.txt — Phase 6 / plan 06-08
#
# Files that predate Phase 6 and legitimately contain one of:
#   font-medium, font-bold, font-light
#   text-base, text-xl, text-3xl, text-4xl
# These are excluded from `make lint-typography` by basename.
#
# Rules:
#   - New files created in plans 06-01 through 06-07 MUST NOT appear here
#     (they shipped under the Phase 6 typography discipline and must not
#     regress). The grep is `--exclude=<basename>` (from Makefile target).
#   - Each entry is a path from repo root. The lint target strips to
#     basename before passing to `grep --exclude`. Basenames in the
#     tree are unique as of plan 06-08 (verified).
#   - Blank lines and `#`-prefixed comments are ignored.
#
# Source of truth for "pre-Phase-6":
#   `git rev-parse (first-06-01-commit)^` resolved at the time this file
#   was authored. A file that existed at that snapshot and contained a
#   forbidden class goes here; a file newly created in Phase 6 does not.
#
# Gradual migration story: downstream plans (06-09+, Phase 7+) are
# expected to tighten the allowlist by migrating grandfathered files
# onto the Phase 6 typography scale and deleting their entries here.
